# Nashville Housing SQL Data Cleaning & Transformation Project

## Overview

This project was one of my first forays into using SQL for data cleaning and preparation. I completed the project as part of my development as an aspiring Business Analyst, using a guided project from Alex The Analyst as an opportunity to build practical SQL skills.

The primary goal was to take a raw, unstructured dataset and transform it into a cleaner, more consistent dataset that could be used for analysis.

Rather than focusing solely on producing a final dataset, this project helped me understand the thought process behind identifying data-quality issues, determining how they should be handled, and using SQL to systematically transform the data.

**What I Worked On**

Throughout the project, I practiced using SQL to:

- Inspect a raw dataset and identify potential data-quality problems

- Identify and remove duplicate records

- Examine missing and null values

- Standardize inconsistent data

- Transform and format columns

- Create new fields from existing data

- Update records while preserving the original dataset

- Organize the cleaned data into a format suitable for analysis


This project was particularly valuable because it introduced me to the idea that data analysis begins before the analysis itself. I also became more comfortable using SQL as a data preparation tool, rather than thinking of SQL solely as a way to retrieve information from a database.

Some of the key concepts I gained experience with include:

- SELECT and filtering data

- WHERE conditions

- CASE statements

- UPDATE statements

- DELETE statements

- ALTER TABLE

- String manipulation and formatting

- Identifying duplicate records

- Working with null and missing values

- Creating and modifying columns

- Using temporary tables to safely manipulate data

### Key Takeaway

One of my biggest takeaways from this project was learning that cleaning data requires judgment, not just syntax.

Writing the SQL query is only part of the process. Before changing a dataset, I need to understand why a record is considered problematic, determine what the appropriate treatment should be, and verify that the transformation produced the intended result.

This project gave me a foundation for approaching SQL more confidently and provided the starting point for applying SQL to more independent analytical projects.
